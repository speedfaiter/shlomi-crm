# אוטומציית תגובה ← הודעה (אינסטגרם של שלומי חן)

- **דף ניהול:** https://instagram-dm.shlomichen.workers.dev/admin (שם משתמש: כל מילה. סיסמה: אצל שלומי בקובץ `secrets.local.txt` במק. לעולם לא לבקש אותה בצ'אט). עובד גם מהטלפון.
- **קוד:** GitHub `speedfaiter/shlomi-crm`, ענף `claude/bold-rubin-9vnmaa`, תיקייה `instagram-dm/`. במק: `~/Downloads/shlomi-crm-claude-bold-rubin-9vnmaa/instagram-dm`.
- **אפליקציית מטא:** MBTM Message Assistant (מסלול API setup with Instagram login). מפורסמת (Published).
- **מסמך טכני מלא:** `instagram-dm/HANDOFF.md` בריפו.

- **שאלון לידים** (איפה, נמצאים, נתניה, אור עקיבא, אימון, פרטים, מחיר, אונליין, ליווי...): שם הילד, גיל, מטרה, אזור, ניסיון קודם → אימון היכרות 119₪ / שיחת ייעוץ 49₪ / ליווי אונליין / קורסים ומדריכים. הלידים מופיעים בדף הניהול.

## איך מוסיפים אוטומציה לסרטון חדש (הדרך הרגילה)
צריך משלומי רק: **המילה** שהוא אומר בסרטון לכתוב, ו**הלינק** למדריך. ואז בדף הניהול, בכרטיס "חוק חדש":
1. איפה כותבים: **תגובה על פוסט/ריל**.
2. מילת המפתח (כמה מילים מפרידים בפסיק).
3. על איזה ריל: לוחצים על **התמונה של הסרטון** (מופיעה רק אחרי שהוא עלה). חוק של ריל מסוים גובר על חוק כללי עם אותה מילה.
4. ההודעה, למשל: `הנה המדריך ל... 🎁 בתיאבון!` (`{username}` = שם המגיב).
5. כפתור: טקסט קצר (עד 20 תווים) + הלינק (חייב להתחיל ב-https://).
6. לסמן **הודעה מקדימה** ו/או **לעוקבים בלבד** לפי הצורך.
7. תגובה פומבית: כמה נוסחים, אחד בכל שורה (למשל "שלחתי לך בפרטי 💌").
8. **הוספה**.
לכתוב לשלומי את כל הטקסטים מוכנים להדבקה, בעברית, בטון שלו.

**לפני שמוסיפים מדריך שהוא דף Claude (claude.ai/artifact):** לוודא שהוא משותף לכולם (Share), ושנפתח בחלון גלישה בסתר בלי התחברות.

## כללי עבודה עם שלומי
- עברית פשוטה, צעד אחד בכל פעם ואז לחכות. לכל צעד: למה, איפה ללחוץ, איך יודעים שהצליח.
- לעולם לא לבקש סיסמה/טוקן/סוד בצ'אט. סודות נכנסים רק בטרמינל (למשל `pbpaste | tr -d ' \n' | npx wrangler secret put NAME` אחרי שהעתיק).
- לא ללחוץ "חיבור מחדש" בדף הניהול (מסלול ה-OAuth שבור; החיבור נעשה עם טוקן ידני).
- לפני שינוי עיצוב דף הניהול: הדמיה ואישור.
- לא להפעיל את אותה מילה גם במניצ'אט או כלי אחר (יישלחו שתי הודעות).

## מה בודקים כשמשהו לא עובד
1. **"פעילות אחרונה"** בדף הניהול: נשלח / נכשל (עם הסיבה) / ריק.
2. ריק? בטרמינל במק: `cd ~/Downloads/shlomi-crm-claude-bold-rubin-9vnmaa/instagram-dm && npx wrangler tail`, ותגובה חדשה מחשבון **אחר** (לא מ-@shlomichen1).
   - `bad signature` → הסודות IG_APP_SECRET / META_APP_SECRET לא תואמים. להכניס מחדש (App settings ← Basic ← App secret, ו-API setup with Instagram login ← Instagram app secret).
   - `comment ... no rule` → המילה לא תואמת לחוק (מילה שלמה, אות ו/ה/ל/ב/ש לפניה מותרת).
   - אין `POST` בכלל → במטא: שדות comments / messages / messaging_postbacks מנויים, ומתג "מינוי ל-Webhook" ליד shlomichen1 דלוק.
3. ראש דף הניהול צריך להראות "מחובר @shlomichen1" בלי שגיאה אדומה. שגיאת טוקן → Generate token במטא ולהכניס מחדש לפי HANDOFF.md.
4. יותר מ-150 הודעות בשעה נכנסות לתור ויוצאות לאט. זה תקין.

## עדכון קוד
הורדת ZIP של הענף, העתקת `src/` לתיקייה במק, ואז `npx wrangler deploy` (הפקודה המלאה ב-HANDOFF.md). שינוי מסד נתונים: קובץ SQL חדש ו-`npx wrangler d1 execute instagram-dm --remote --yes --file=...`.
