# תגובה ← הודעה

מחליף חינמי למניצ'ט: מי שמגיב מילת מפתח על פוסט או ריל באינסטגרם, מגיב לסטורי או שולח הודעה עם המילה, מקבל אוטומטית הודעה פרטית עם קישור.

- דרך ה-Instagram API הרשמי של מטא, עם אפליקציה משלכם. בלי לתת סיסמה.
- רץ בתוכנית החינמית של Cloudflare (Workers + D1).
- דף ניהול בעברית: מילות מפתח, בחירת ריל, כפתור בהודעה ותגובה פומבית.
- עד 150 הודעות בשעה, והשאר בתור.

## איך מקימים
